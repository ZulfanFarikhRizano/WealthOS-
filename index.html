📦 Setup Database Gratis (JSONBin.io)

JSONBin.io adalah database gratis untuk menyimpan data kamu di cloud. Ikuti langkah berikut:

1
Buka jsonbin.io di browser → klik Sign Up → daftar gratis (bisa pakai Google)
2
Setelah login, klik API Keys di menu atas → klik "+ Create Access Key"
3
Beri nama key (bebas, misal: wealthos) → klik Generate → copy API key yang muncul
4
Paste API key di bawah ini → klik Simpan & Lanjut
⚠️ API key tersimpan hanya di browser kamu, tidak dikirim ke server manapun selain JSONBin.io
✅ JSONBin gratis sampai 10.000 request/bulan — lebih dari cukup untuk penggunaan pribadi.
✅ Data kamu private dan hanya bisa diakses dengan API key kamu sendiri.
